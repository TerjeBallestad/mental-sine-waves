# Design Pillars

Pillar 1: Empatisk nysgjerrighet: Hver karakters personlighet oppstår ut ifra enkle systemer som spilleren kan utforske og som er tankevekkende og skaper nysgjerrighet.
Pillar 2: Tilfredsstillende vekst: Spillet har en kunstnerisk stil, farger og systemer som er både koselig og tilfredsstillende å se på. Spilleren opplever mestring og glede av å se karakterer og tall vokse.
Pillar 3: Humoristisk kontrast: Humoren er aldri langt unna, noe som skaper letthet mellom de emosjonelle øyeblikkene.
